# Non-functional requirements checklist

Source: [spec section 2](../spec/vigil-spec.md#2-non-functional-requirements), including [Added for the real-world environment](../spec/vigil-spec.md#added-for-the-real-world-environment-nov-2-1) and [Added for compute and budget](../spec/vigil-spec.md#added-for-compute-and-budget-nov-2-1). The tables list **37** NFRs (NFR-001 to NFR-037).

Every target is checked by a script or test, and the result is published even when missed. Targets marked ⚠️ are **first estimates**: Meta does not publish response times, so the first measured values are recorded in [EVAL.md](../../EVAL.md) before the benchmark run and the targets stay fixed after that.

Status and Blocked-by values are defined in the [functional checklist legend](functional.md#legend). **Status as of Mon Nov 2, 2026, 13:15 PT**, from `uv run pytest -q -rA` (800 passed, 1 failed, 12 deselected) and `uv run pytest -m e2e tests/e2e -q` (12 passed, Chromium); CI evidence: `<CI run URL>` at `<commit>`. Many NFRs are measurements on the real system: where only the measuring code is tested, the row is *Partial (offline)*; where nothing can be measured yet, it is *Blocked*. No row is *Verified*.

The [Nov 2 change set](../spec/changes/2026-11-02-business-corrections.md) changed NFR-002 (voice-rule audio fixtures), NFR-003 (more forbidden fields), NFR-024 (landmark reprojection thresholds), NFR-036 (`credit`-tagged spend) and NFR-037 (the $25 judging allowance). The rows below use the current spec text.
